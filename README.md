# EduBridge

## Project Overview

EduBridge is an educational management system developed as part of the Software Construction course project. The purpose of the system is to improve communication and collaboration among students, teachers, and administrators through a centralized platform.

---

## Objectives

- Improve communication between stakeholders.
- Provide a centralized educational platform.
- Manage academic information efficiently.
- Enhance accessibility and transparency.
